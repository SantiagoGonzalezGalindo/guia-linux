# Guía de configuración de Linux

Guía práctica para montar una red privada entre tu laptop con Linux y tu celular, controlarla por SSH desde el teléfono, y dejar la terminal más cómoda de usar.

**Léela aquí: https://santiagogonzalezgalindo.github.io/guia-linux/**

Probada en Nobara Linux con KDE Plasma sobre Wayland. Aplica igual en Fedora y derivados; en Ubuntu o Debian solo cambia el gestor de paquetes. La parte del celular funciona en iOS y en Android.

El contenido vive en index.md.
